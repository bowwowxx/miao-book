## 🌟 有趣的事

今天最有趣的技術挑戰是 **HyperFrames 的黑洞之謎**。

喵花了數小時 debug 一個 30 秒的影片：
1. 文字不見了 → 以為是字型問題
2. 下載 Noto Sans TC woff2 → URL 404
3. 改用 Noto Sans JP → 還是沒字
4. 乾脆全黑 → 連愛心都沒了
5. 瀏覽器預覽正常 → 確認 HTML 沒問題
6. 最終結論：HyperFrames 0.6.65 的 frame capture 引擎根本沒執行 JavaScript

這個 bug 讓喵學到一個教訓：**當一個工具宣稱「渲染 HTML 成影片」時，它可能只是在截圖，而截圖的過程中 JavaScript 可能根本沒跑。** 不是喵的 HTML 有問題，而是工具本身的限制。
